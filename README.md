# نظام الوثائق والمحفوظات — إدارة التعليم بمنطقة حائل

أرشفة إلكترونية للتعاميم والمستندات مع ذكاء اصطناعي (OCR + تلخيص + تصنيف + بحث ذكي).
**التقنيات:** Python (Flask) · MySQL · HTML · CSS

## التشغيل (ويندوز)

1. ثبّت: Python 3.10+ ، MySQL ، **Tesseract OCR** (مع حزمة اللغة العربية `ara`)
   - تنزيل ويندوز: https://github.com/UB-Mannheim/tesseract/wiki  (اختر Arabic أثناء التثبيت)
   - بعد التثبيت أضف مجلده (مثل `C:\Program Files\Tesseract-OCR`) إلى PATH
   - لملفات PDF الممسوحة ضوئياً ثبّت أيضاً **Poppler** وأضفه إلى PATH
2. أنشئ قاعدة البيانات: افتح MySQL وشغّل ملف `schema.sql`
3. انسخ `.env.example` إلى `.env` وعدّل بيانات MySQL و SECRET_KEY
4. من مجلد المشروع:
```
pip install -r requirements.txt
python seed.py          # ينشئ المدير: admin / admin123  (غيّر كلمة المرور!)
python app.py
```
5. افتح http://localhost:5000

### الترقية إلى التاريخ الهجري (لقاعدة بيانات قائمة)
> ⚠️ **خذ نسخة احتياطية من قاعدة البيانات قبل تشغيل الترحيل**، مثلاً:
> ```
> mysqldump -u root -p archive_db > backup_before_hijri.sql
> ```
> (وانسخ مجلد `uploads/` أيضاً). لا تُعِد تشغيل `schema.sql` على قاعدة قائمة.

```
pip install -r requirements.txt   # يضيف hijri-converter
python migrate_hijri.py
```
السكربت يضيف العمود `doc_date_h` (هجري بصيغة `YYYY-MM-DD`) ويملؤه من النص القديم `doc_date`:
الهجري يُنقل، والميلادي الواضح يُحوَّل إلى هجري، والغامض يُترك فارغاً، ويطبع ملخصاً بأرقام الوثائق
التي تُركت بلا تاريخ لتعديلها يدوياً. لا يحذف شيئاً، ولا يغيّر `doc_date`، ولا يكتب فوق تاريخ موجود،
ويمكن تشغيله أكثر من مرة.

### الترقية إلى سجل التعديلات (لقاعدة بيانات قائمة)
> ⚠️ **خذ نسخة احتياطية قبل التشغيل** (حتى لو أخذت واحدة قبل الترحيل السابق):
> ```
> mysqldump -u root -p archive_db > backup_before_edit_log.sql
> ```

```
python migrate_edit_log.py
```
يضيف إلى `documents` العمودين `updated_at` و `updated_by`، وينشئ جدول `document_edits`. آمن للتشغيل أكثر من مرة،
ولا يحذف ولا يعدّل أي بيانات. الوثائق الموجودة تبقى «لم تُعدَّل منذ رفعها» (`updated_at` فارغ).

### فهرس تاريخ الرفع (لقاعدة بيانات قائمة)
> ⚠️ **خذ نسخة احتياطية قبل التشغيل**: `mysqldump -u root -p archive_db > backup_before_created_index.sql`

```
python migrate_created_index.py
```
يضيف فهرساً على `documents.created_at` لتسريع البحث بتاريخ الرفع. آمن للتشغيل أكثر من مرة ولا يغيّر أي بيانات.

### مصدر تاريخ الوثيقة وتعبئة الوثائق القديمة (لقاعدة بيانات قائمة)
> ⚠️ **خذ نسخة احتياطية قبل التشغيل، وخصوصاً قبل `--apply`**:
> ```
> mysqldump -u root -p archive_db > backup_before_doc_dates.sql
> ```

```
python migrate_doc_date_source.py          # يضيف العمود doc_date_source (auto / manual / backfill)
python backfill_doc_dates.py               # تجربة فقط: يعرض ما سيُعبّأ وما سيُترك ولماذا، دون أي كتابة
python backfill_doc_dates.py --apply       # تنفيذ فعلي
python backfill_doc_dates.py --apply --use-ai   # اختياري: يستعين بـ Gemini (يرسل نص الوثائق إلى Google)
```
السكربت يعمل فقط على الوثائق التي بلا تاريخ وثيقة، ولا يكتب فوق تاريخ موجود، ولا يعبّئ إلا تاريخاً واحداً واضحاً
مقترناً بكلمة «التاريخ» أو ما يشبهها. يُسجَّل كل ما يعبّئه في سجل التعديلات بوصف «تعبئة تلقائية لتاريخ الوثيقة»
دون تغيير «آخر تعديل». ما يتركه يُكمَّل يدوياً من صفحة **«وثائق تحتاج تاريخاً»** (`/missing-dates`).
تشغيله مرتين لا يكرر شيئاً.

## تاريخ الوثيقة وتاريخ الأرشفة
معلومتان مختلفتان لا تحل إحداهما محل الأخرى: **تاريخ الوثيقة** هو تاريخ إصدارها المكتوب في ترويستها
(يُستخرج عند الرفع: Gemini أولاً ثم تعابير نمطية على النص، والميلادي يُحوَّل إلى هجري، وعند الشك يُترك فارغاً)،
و**تاريخ الأرشفة** هو وقت إضافتها للنظام (يُسجَّل تلقائياً). بعد اختيار الملف في صفحة الرفع يُعبَّأ تقويم تاريخ
الوثيقة بما استُخرج ويمكن تغييره قبل الحفظ. إن لم يُحدَّد تاريخ تُعرض الوثيقة بشارة «غير محدد» مع نموذج لإضافته.

## البحث بين تاريخين
فوق خانتي «من / إلى» زر تبديل: **تاريخ الوثيقة** (الافتراضي، العمود `doc_date_h`) أو **تاريخ الرفع**
(`created_at`، اليوم الذي أُضيفت فيه الوثيقة للنظام). في وضع تاريخ الرفع يُحوَّل اليومان الهجريان إلى ميلادي
ويُحسب اليوم كاملاً بتوقيت الرياض (من 00:00 حتى نهاية يوم «إلى»)، ثم يُقارن مع `created_at` المخزّن بتوقيت UTC.

## سجل التعديلات
كل تعديل فعلي على وثيقة يُسجَّل بوقته ومن قام به وما الذي تغيّر (القيمة القديمة والجديدة للحقول القصيرة،
و«تم تعديله» فقط للملاحظات والملخص). الحفظ دون تغيير لا يُسجَّل. يظهر في صفحة الوثيقة: «آخر تعديل» و«سجل التعديلات».
الأوقات تُخزَّن بتوقيت UTC وتُعرض بتوقيت الرياض (UTC+3).

## التواريخ
كل تواريخ الوثائق **هجرية** (تقويم أم القرى). لا يُكتب التاريخ يدوياً: يُستخرج تلقائياً من الوثيقة عند الرفع،
ويُعدَّل بالاختيار من تقويم هجري منبثق (`static/hijri-picker.js`، بلا مكتبات ولا إنترنت). في صفحة الأرشيف
يمكن البحث بين تاريخين. النص الأصلي للتاريخ يبقى محفوظاً في `doc_date` للأرشيف.

> للتجربة السريعة بدون MySQL: ضع `DB_ENGINE=sqlite` في `.env` (للتجربة فقط).

## ميزات الذكاء الاصطناعي (`ai.py`) — تعمل محلياً بدون إنترنت
1. **OCR عربي:** يقرأ الصور والـ PDF الممسوح (Tesseract). PDF النصي يُقرأ مباشرة.
2. **استخراج الحقول:** رقم الوثيقة، التاريخ (هجري/ميلادي)، العنوان من "الموضوع".
3. **تصنيف تلقائي:** تعميم / قرار / محضر / خطاب… بالكلمات المفتاحية.
4. **تلخيص:** استخراجي (أهم الجمل حسب تكرار الكلمات).
5. **بحث ذكي:** تطبيع عربي + تجذيع خفيف + مرادفات (إجازة ↔ عطلة) + ترتيب بالأقرب.
